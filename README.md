# AI-Based Smart Healthcare Diagnosis and Decision Support System

## Project Overview

The **AI-Based Smart Healthcare Diagnosis and Decision Support System** is an educational AI prototype designed to analyze patient symptoms and provide AI-assisted healthcare decision support.

The system accepts patient details and symptoms as input, processes them using a healthcare knowledge base, and applies multiple Artificial Intelligence techniques to identify possible conditions and provide an understandable health assessment.

> **Note:** This is an educational prototype and is not a clinical diagnosis system.

---

## Objectives

- To develop an AI-based healthcare decision support system.
- To analyze patient symptoms using a structured knowledge base.
- To implement Logical Reasoning for symptom matching.
- To use Bayesian Reasoning for estimated condition probabilities.
- To use A* Search for diagnostic path finding.
- To integrate the AI techniques using an Intelligent Agent.
- To provide the results through a user-friendly dashboard.

---

##  AI Techniques Used

### 1. Logical Reasoning

Compares patient symptoms with the symptoms stored in the healthcare knowledge base and identifies matching conditions.

### 2. Bayesian Reasoning

Calculates an estimated model probability for possible conditions based on the entered symptoms and ranks them accordingly.

### 3. A* Search

Uses path cost and heuristic values to find a suitable diagnostic decision path.

Example:

```text
Start
   ↓
Fever Check
   ↓
Respiratory Check
   ↓
Flu Assessment
4. Intelligent Agent

Combines the outputs from Logical Reasoning, Bayesian Reasoning, and A* Search to generate the final decision-support result.
